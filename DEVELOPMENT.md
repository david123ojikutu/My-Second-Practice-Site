For my second practice website, I decided to create an "Art Hub," a creative space centered around exploring visual work, discovering new ideas, and enjoying artwork in a calm and thoughtful way. I wanted the site to feel welcoming and reflective, while also making it easy to browse and spend time with each individual piece. Unlike my first practice site, I wanted this one to feel more like a real gallery website rather than simply a classroom exercise.

I began with the basic HTML boilerplate, including &lt;!DOCTYPE html&gt;, &lt;html lang="en"&gt;&lt;/html&gt;, &lt;head>&lt;/head>, and &lt;body>&lt;/body>. Inside the &lt;head>&lt;/head>, I added a &lt;meta charset="UTF-8"&gt; element to specify the character encoding and a &lt;meta name="viewport" content="width=device-width, initial-scale=1.0"&gt; element to help the website display properly across different screen sizes. I also added a &lt;title>Art Hub</title> element to give the page its title. I then added several &lt;link> elements to practice working with external links and site resources, including a favicon, an Apple touch icon, different favicon sizes, a web manifest, and an external stylesheet through &lt;link rel="stylesheet" href="style.css"&gt;.

I then added a &lt;header>&lt;/header> containing a main title &lt;h1>Art Hub</h1> and three introductory &lt;p>&lt;/p> elements. The first paragraph explains the purpose and atmosphere of Art Hub. The second introduces a partnership with &lt;a href="[https://visualartspassage.com/](https://visualartspassage.com/)" target="_blank"&gt;Visual Arts Passage</a>, with the target attribute set to "_blank" so that the link opens in a new tab. The third paragraph explains the site's philosophy of giving artwork room to breathe through clear presentation, meaningful descriptions, and atmosphere.

After that, I added a &lt;main>&lt;/main> containing a &lt;section>&lt;/section> for the featured artwork. I included three different pieces, each following a similar structure. Each artwork has a &lt;h2>&lt;/h2> heading identifying it as a featured artwork, followed by a &lt;p>&lt;/p> describing the piece. I then used a &lt;figure>&lt;/figure> containing an &lt;img src="" alt=""&gt; and a &lt;figcaption>&lt;/figcaption> to provide a more detailed description of the artwork. I made sure to include descriptive alt text for each image so that the images would remain accessible. After each artwork, I added a &lt;h3>Why it stands out</h3> heading followed by a &lt;p>&lt;/p> explaining what makes that particular piece interesting. Finally, I added an empty &lt;footer>&lt;/footer> at the bottom of the page.
