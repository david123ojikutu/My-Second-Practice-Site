# My-Second-Practice-Site
This is just a practice site for me to practice what I'm learning in HTML, CSS, and JavaScript. For this exercise, I've decided to create "Art Hub", a fictional online space for students to discover artwork, browse featured artists, and submit their own creations. Because I've already created a <a href="https://github.com/david123ojikutu/My-First-Practice-Site/tree/main">first practice site</a> (hence why this is my second one), I have an idea of all the things a website can and should have. So I also created a <a href="Things for Code.txt">text document</a> that lists every HTML element and attribute I've learnt so far, as a way of gauging myself in how well I understand the content of my learning. The goal is to use every item mentioned in the document in a manner that's coherent and appropriate for the kind of website I'm creating. Without further ado, welcome to <a href="https://david123ojikutu.github.io/My-Second-Practice-Site/">Art Hub</a>.
